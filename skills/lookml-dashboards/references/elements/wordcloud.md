# LookML Dashboard Element Vis Config: Word Cloud

This reference provides exact visualization configuration options for Word Cloud elements in LookML dashboards.

## Options Reference Table

| Option Key / Path | Type | Label | Description |
| :--- | :--- | :--- | :--- |
| `color_application.options.reverse` | `boolean (true/false)` | `Reverse colors` | Toggle to reverse color palette orientation |
| `modern2026` | `boolean (set to true, otherwise omit)` | `Modern 2026 Engine` | Enable modern 2026 visualization rendering engine (default: `true`, otherwise omit) |
| `rotation` | `boolean (true/false)` | `Rotation` | Allow random word rotation angles |
